## 2026-09-22 — ordered_mesh_atlas_v1

- 기준 커밋: `bc24ab2`.
- 관측: 사용자 제공 FPS 52.7~54.2, 평균 draw 679.3~720.7/프레임.
- 가설: 메시 종류가 교차할 때 생기는 geometry 배치 분할이 CPU 제출 비용을 늘린다. FPS의 실제 병목은 미확정.

- 자료: `baseline_2026-09-22.txt`, `2026-09-22-render-batching-report.md`.
- 이후 실행 자료: 실행 파일 옆 `Logs/renderer_*.csv`, `.log`; `Tools/analyze_render_log.py`로 비교 리포트 생성.
- 검증: 정적 검토 대상. 사용자 요청에 따라 빌드/실행/실측하지 않음.
- 결론: 구현 완료 후 동일 조건의 실측을 추가해야 한다. 변경 후 draw/FPS 수치를 추정값으로 채우지 않는다.
